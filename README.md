# 🛍️ StyleHub - Fashion E-Commerce Website

A modern and responsive fashion e-commerce website built using ReactJS and Tailwind CSS.

---

## 🚀 Live Demo

https://style-hub-seven-omega.vercel.app/

---

## ✨ Features

- 🏠 Hero Section
- 👕 Product Listing
- 🛒 Add to Cart UI
- 🔥 Smooth Scroll Shop Now
- 📱 Responsive Design
- 🎨 Modern UI using Tailwind CSS

---

## 🛠️ Tech Stack

- ReactJS
- Tailwind CSS
- JavaScript
- React Router DOM
- Vite
